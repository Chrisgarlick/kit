Component catalogue

Every piece kit could ship, working, in one system.

These are live: type, click, drag, sort, tab through them. One set of tokens drives everything here, so the scheme, density and accent controls above re-theme the whole page at once. Each card says whether it's CSS only (tier 1) or a component with behaviour (tier 2), and which accessibility pattern it follows.

        What does an audit check?
        SEO, accessibility, security, performance, content and structured data, on every page it can reach.
        How long does it take?
        A small site takes a minute or two. Large sites crawl politely, a few pages at a time.
        Can I schedule audits?
        Yes, daily, weekly, fortnightly or monthly, once the site is verified.
